# 📘 个人 AI 知识库日常使用与运作指南

本文档介绍本知识库的结构组织方式以及后续如何让我（AI 助手）每天为你收集沉淀前沿 AI 知识。

---

## 🔄 日常运作机制：如何让 AI 每日收集？

### 方式 1：随时直接在对话中触发（最推荐）
每天你打开与我的对话，直接发送任一指令：
- **`今日AI日报`** 或 **`收集今日AI知识`**
- 我会自动：
  1. 联网追踪当天或近期 GitHub Trending、顶会/顶级实验室开源的 AI 工具与最佳实践；
  2. 过滤无价值的炒作新闻，提取具有**实际工程落地价值**的工具与方案；
  3. 按照标准模板自动创建 `01-Daily-Digest/YYYY/YYYY-MM/YYYY-MM-DD-AI-Digest.md`；
  4. 自动把高星工具/突破性实践提取为 `03-Tools-and-Projects/` 和 `04-Engineering-Practices/` 中的独立卡片，并自动建立 Obsidian 双向链接。

### 方式 2：按需定制专项沉淀
当你遇到特定兴趣点时，可以直接告诉我：
- *“帮我调研一下当前最火的 Coding Agent 开源项目，沉淀到工具卡片”*
- *“帮我写一份企业知识库构建中 Parent-Child Chunking 的最佳实践笔记”*
- 我会直接生成标准格式的 Markdown 卡片归档到对应目录。

---

## 🗂️ 目录与标签规范

- **`00-Home/`**：
  - `000-AI-Index.md`：知识库导航地图（MOC），整合各核心专题。
- **`01-Daily-Digest/`**：
  - 按 `年/年月/年月日-AI-Digest.md` 存放每日资讯流。
- **`03-Tools-and-Projects/`**：
  - 核心开源框架与工具库，包含 GitHub 地址、核心特性、架构亮点与快速启动示例。
- **`04-Engineering-Practices/`**：
  - 解决实际生产问题的工程架构方案、避坑指南与示例代码。
- **`99-Templates/`**：
  - 提供 Obsidian 标准模板，保证后续卡片格式一致与元数据（Frontmatter）规范。

---

## 💡 推荐 Obsidian 插件搭配

1. **Dataview**（必装）：
   - 可以通过类似 SQL 的语法动态检索知识库。例如在首页自动列出所有包含 `#ai-tool` 的项目列表。
2. **Omnisearch**：
   - 带来超强的本地语义混合搜索体验。
