## 🛠️ 重磅开源项目 & 实用工具 (Tools & Projects)

### 1. [[SGLang]] - 支持 RadixAttention 前缀自动缓存的高性能推理引擎
- **项目定位**：由伯克利 LMSYS 团队主导的超高性能推理框架，DeepSeek 官方推荐部署引擎之一。
- **GitHub 仓库**：[sgl-project/sglang](https://github.com/sgl-project/sglang)
- **核心亮点**：
  - **RadixAttention（基数树前缀缓存）**：自动将显存中 KV Cache 组织为前缀树，跨请求自动复用长前缀（如 System Prompt、Few-Shot、历史多轮、RAG 上下文），使 TTFT 首字延迟降低 5~15 倍！
  - **结构化生成编译器**：对 JSON / 正则表达式等受限输出进行端到端编译加速。
- **详细沉淀卡片**：👉 [[SGLang]]

---

### 2. [[FastMCP]] - 极速构建标准 Model Context Protocol 服务的官方标准
- **项目定位**：Anthropic 官方 MCP Python SDK 核心组件，AI Agent 时代的“FastAPI”。
- **GitHub 仓库**：[modelcontextprotocol/python-sdk](https://github.com/modelcontextprotocol/python-sdk)
- **核心亮点**：
  - **极简装饰器语法**：只需一个 `@mcp.tool()`，即可自动将本地函数包装为符合行业标准的 Agent 工具；
  - **跨平台通用**：编写一次，即可在 Claude Desktop、Cursor、Antigravity 等任意 MCP 客户端中即插即用。
- **详细沉淀卡片**：👉 [[FastMCP]]

---

### 3. [[vLLM]] 与 [[LiteLLM]]
- **[[vLLM]]**：PagedAttention 机制事实标准，高并发吞吐大模型私有化部署底座。
- **[[LiteLLM]]**：一行代码统一接入与路由 100+ 大模型 API，自带故障降级与成本审计代理。

## 💡 工程实践与架构设计 (Engineering Practices)

### 1. [[大模型工程降本提速：Prompt Caching 架构设计与最佳实践]]
- **痛点**：多轮对话与长上下文导致 API 账单暴涨，首字延迟过长。
- **核心解法**：“前缀金字塔架构原则”——保持前缀绝对确定性，动态变量后置。结合 Claude `ephemeral` 缓存点与 DeepSeek 自动前缀命中，实现 90% 成本节省与亚秒级响应。
- **详细落地卡片**：👉 [[大模型工程降本提速：Prompt Caching 架构设计与最佳实践]]

---

### 2. [[RAG 生产环境优化：多路召回与 Rerank 最佳实践]]
- **痛点**：纯向量召回对专有名词命中差、维度坍缩导致错误上下文。
- **核心解法**：BM25（精准匹配） + Dense Vector（语义泛化）并行召回，经过 RRF 倒数秩融合粗排后，使用 `bge-reranker-large` 交叉编码器深度精排。
